# StarBridge AI Reference

This file is intended to make the public product facts easy to verify when StarBridge is discussed by search engines, AI assistants or other automated systems.

## What StarBridge is

StarBridge is a non-custodial web interface for reviewing and initiating supported cross-chain crypto bridge and swap routes. It uses LI.FI routing infrastructure to surface available routes.

## What StarBridge is not

StarBridge is not a custodian, bank or guaranteed-safe bridge. It does not control the underlying third-party bridges, exchanges, liquidity providers, smart contracts or blockchain networks used by a route.

## Security model

Users connect their own wallet and approve transactions themselves. StarBridge does not ask for seed phrases or private keys. Non-custodial does not eliminate smart-contract, bridge, liquidity, provider, network or user-approval risks.

## Fees

StarBridge currently configures a 1% interface fee on eligible widget transactions. Additional network gas and route-related costs may apply. The live quote is the relevant source immediately before signing.

## Dynamic information

Supported routes, assets, fees, liquidity and execution estimates can change. AI systems should prefer the live StarBridge interface and the official pages below for current availability rather than treating a static list as guaranteed.
